# Local ONNX stage

SamiBOT can run a detector locally on CPU before using Hugging Face. ONNX Runtime
supports CPU execution, which keeps the runtime dependency small and avoids
shipping PyTorch on the VPS.

## Recommended zero-cost image model

The repository includes an installer for
`onnx-community/ai-image-detect-distilled-ONNX`, an MIT-licensed distilled
ViT image classifier. The model has 11.8M parameters and the pinned INT8 ONNX
file is about 15.3 MB. Its published model card reports 74% validation accuracy
and 72% on a custom real-world set, so it should be treated as screening
evidence rather than an authenticity certificate.

Install it with:

```bash
python scripts/install_ai_detector_models.py
```

Or choose a persistent directory:

```bash
python scripts/install_ai_detector_models.py --dest /opt/samibot-models
```

The installer pins the model revision and verifies its SHA-256 before accepting
the file.

The selected model expects 224x224 RGB images normalized with mean/std
`0.5,0.5,0.5`, and its labels are `fake,real`. The detector adapter is now
configured for that contract.

## Environment

Set:

```bash
AI_DETECT_ONNX_IMAGE_MODEL=/opt/samibot-models/image/model_int8.onnx
AI_DETECT_ONNX_IMAGE_LABELS=fake,real
AI_DETECT_ONNX_IMAGE_SIZE=224
AI_DETECT_ONNX_IMAGE_MEAN=0.5,0.5,0.5
AI_DETECT_ONNX_IMAGE_STD=0.5,0.5,0.5

# Keep CPU usage predictable on a small VPS.
AI_DETECT_ONNX_THREADS=1
```

The bot can still run without this model. If the file is absent, the ONNX stage
returns no result and the normal metadata/local/Hugging Face waterfall continues.

## Audio

The runtime adapter also supports raw-waveform rank-2 ONNX audio classifiers
and can supply an `attention_mask` plus Wav2Vec2-style normalization when
requested:

```bash
AI_DETECT_ONNX_AUDIO_MODEL=/models/voice-detector.onnx
AI_DETECT_ONNX_AUDIO_LABELS=real,fake
AI_DETECT_ONNX_AUDIO_NORMALIZE=1
```

We intentionally do **not** install a large audio transformer by default. A
currently available Apache-2.0 Wav2Vec2 ONNX detector is roughly 355 MB in INT8
and has a ~315M-parameter backbone. That is a much worse fit for a free/low-RAM
VPS than the 15 MB image model. Telegram voice clips therefore keep using the
lightweight local DSP stage and the existing free Hugging Face stage unless an
administrator deliberately provisions the larger audio model.

## Important limitations

- A detector score is not a calibrated probability and does not prove origin.
- AI-generated images can be recompressed, resized, edited, or generated by
  newer systems outside the model's training distribution.
- Metadata/C2PA evidence can be missing, stripped, or forged.
- Audio detection is especially sensitive to codec, microphone, language,
  background noise, and post-processing.
- The waterfall deliberately fails open: a missing/incompatible ONNX model
  never breaks the Telegram bot.

The ONNX adapter refuses model contracts it cannot safely identify instead of
guessing at feature preprocessing. This is important for audio models because
some require mel-spectrogram or other model-specific features.

For ONNX Runtime/Hugging Face integration details, see the official
ONNX Runtime/Optimum documentation.
